## If your launcher does not open (0.6.1)

The 0.6.1 launcher can't update itself, so update by hand once:

1. Download **Uncharted-windows.zip** below.
2. Extract it over your current port folder and allow it to replace files. Your saves, settings and
   shader cache stay (they are in `analysis\uncharted-user`).
3. Start **Uncharted Launcher.exe** again.

On 0.6.0 or older? The launcher offers this update: press **UPDATE TO 0.6.2** next to PLAY.

## Fixed

- **The launcher did not open after updating to 0.6.1** (#208): the 0.6.1 package was missing one of
  the launcher's files. It is included now, and the launcher opens even if that file is missing.

Everything from 0.6.1 is included: fewer random crashes in all three games, 1:1 mouse aiming in
Drake's Fortune, no more RivaTuner flicker and better ultrawide shadows in Uncharted 2. Full details
in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.

> **No game files are included.** You need your own dump of the Collection. Not affiliated with
