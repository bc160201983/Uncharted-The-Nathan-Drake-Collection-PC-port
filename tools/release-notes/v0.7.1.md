A fix for AMD Radeon cards crashing with upscaling or TAA, treasures shown again with upscaling,
and a few launcher fixes.

## Fixed

- **AMD Radeon: crash with FSR upscaling or TAA** (#273 #272, likely #246 #197): the
  character motion vectors (added in 0.5.0) addressed their data in a way AMD's shader compiler
  cut short, so AMD cards stopped on the first upscaled frame. Fixed; the motion vectors stay on
  for AMD. Tested on an AMD RDNA2 GPU and on NVIDIA.
- **Treasures invisible with upscaling** (#260 #225 #209 #136): with DLSS, FSR or TAA upscaling the
  treasure model in the pickup popup and on the Treasures screen was drawn into a picture that is
  never shown (DLAA worked). It now shows with every upscaler.
- **Saves**: a save slot that failed to open was still reported as opened, so a save could fail
  to load without an error. The port now reports it, and has room for more open save slots.
- **Launcher**: Steam now counts play time for the per-game Add to Steam entries (#267; please
  add the games again once); dark title bar (#215); the PlayStation touchpad is shown on the
  Controls page (#214); control labels (#256).

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log, and tell us whether
  it also happens with the 60 FPS limit.
- **GeForce GTX 10-series: crash at start** (#211 #219 #252). Being looked at.
- **Rare "device lost" crashes** during play: please start with `GOW3_GPU_CHECKPOINTS=1` and attach
  boot.log.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.
