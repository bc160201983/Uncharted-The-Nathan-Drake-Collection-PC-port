**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
Support the work on [Patreon](https://www.patreon.com/c/bilalreloaded).

The launcher offers this update: press **UPDATE TO 0.8.2** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

The mouse now aims Uncharted 1's jeep gun, the save list can delete saves and shows a picture of
each one, Uncharted 1's physics behave above 60 FPS, Uncharted 2's convoy truck no longer sinks into
the snow, and multithreaded rendering no longer slows down for the rest of a session after a heavy
moment.

## Mouse and saves

- **Uncharted 1: the jeep's mounted gun with the mouse** (#250): the gun on the back of the jeep
  turned slowly with the mouse, because it still read it as a controller stick. The mouse now aims
  it directly. By **the-best-is-best** (#349).
- **Save list** (#349, by **the-best-is-best**):
  - Arabic save names read properly; long names are cut at a whole character.
  - A save can be deleted from the list: select it and press **Delete** (or **Triangle**) twice.
    It is moved to the `savedata-deleted` folder next to your saves, not erased.
  - Each save shows a picture of the game when it was made, instead of the game's logo.

## Fixed

- **Uncharted 1 above 60 FPS: barrels, crates and bodies**: at 120 FPS, objects that should fall
  or roll could stop and hang in the air, and bodies settled too early. The game's physics counted
  in steps of a 60 FPS frame; they now count in time, so objects move as at 60 FPS.
- **Uncharted 2 chapter 21 (the convoy): Elena's truck sinks into the snow** for a moment after a
  bump. A value the game never sets was read as "follow the truck's own last position", so the
  bump's movements piled up. Only the part the game sets is read now.
- **Uncharted 3, the chateau: rows of bright blue dots** with DLSS, FSR, XeSS or TAA. Some wall
  panels are single flat quads, which the anti-aliasing treated as full-screen passes and did not
  shift with the rest of the scene; the gaps between them showed through. They are shifted now.
- **Flicker with DLSS, FSR, XeSS or TAA: Uncharted 1's boat details and Uncharted 3's London bar
  surfaces** are now drawn in step with the rest of the scene.
- **Three rare crashes:** the texture cache could read an image's settings after they were moved
  in memory; the GPU command processor could wait forever when its two command streams were out
  of step; and a sound in a format the port does not play (AAC) closed the game. The sound now
  stays silent instead.
- **Updates and the launcher** (#349): an update that fails halfway is rolled back completely, files
  the update could not replace are kept aside instead of lost, and a damaged game update file gives
  a clear message.

## Faster

- **Multithreaded rendering (on by default in Uncharted 3) after a heavy moment** (#356): the port
  copies each draw's small blocks of constant data into a ring of video memory. After a moment where
  the graphics card fell behind, a part of that ring was never marked free again, so for the rest
  of the session every draw's constants took a slower path, with a driver call each time. The ring
  now frees that part.
- **Shader lookups:** the threads that prepare draws and the one that sends them no longer queue
  behind each other on every shader lookup.

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): a file of the game is
  missing from those dumps (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files**
  in the launcher shows it.
- **NVIDIA: "device lost" after some time in Uncharted 2 and 3** (#316 #314 #277 #76 #224 #249):
  not solved yet. If it happens, please attach your boot.log.
- **Game version 1.00 without update 1.02:** most of the port's fixes need update 1.02. Support for
  1.00 is being worked on.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more
   are recommended; for 2-4 GB cards, try **Save video memory** (experimental).
