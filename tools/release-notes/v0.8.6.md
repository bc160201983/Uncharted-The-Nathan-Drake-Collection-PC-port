The launcher offers this update: press **UPDATE TO 0.8.6** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

This update brings back the launcher of 0.8.4. The games are the same as in 0.8.5.

## Launcher

- **The launcher is back to the one from 0.8.4** (#402 #401): in 0.8.5 it came out oversized and
  distorted on many PCs, and the optional controller mode showed black pages. The controller mode
  is taken out for now. Your settings are kept.
- The Uncharted 2 HUD setting for ultrawide screens (Display -> HUD) stays.

## Still in this version (from 0.8.5)

- **Intel graphics, Uncharted 3 chapter 2 (and chapter 6): "device lost" fixed** (#384 #385 #365
  #328 #138).
- **Uncharted 2, chapter 21 convoy: crash above 60 FPS fixed** (#381 #346), with and without
  update 1.02.

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Uncharted 2, chapter 22: the graphics card stops** (#373 #106): being looked at. If it happens
  to you, please attach your boot.log with the breadcrumbs on and a save from just before it.
- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): a file of the game is
  missing from those dumps (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files**
  in the launcher shows it.
- **NVIDIA: "device lost" after some time in Uncharted 2 and 3** (#316 #314 #76 #224 #249):
  please attach your boot.log with the breadcrumbs on if it still happens.
- **Uncharted 1, mouse ignored for about a second when aiming from cover** (#366): being looked at.
