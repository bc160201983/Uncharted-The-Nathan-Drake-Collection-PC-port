On 0.6.0 or older? The launcher offers this update: press **UPDATE TO 0.6.1** next to PLAY.

Fewer random crashes in all three games, 1:1 mouse aiming in Drake's Fortune, no more RivaTuner
flicker, and better ultrawide shadows in Uncharted 2.

## Fixed

- **Fewer random crashes in all three games** (crashes like "execute access to 0" or a sudden
  close to the desktop, possibly also #205): the PS4 code keeps some values just below the stack,
  and when Windows handled a page fault in such a routine it could overwrite them. We had fixed
  two of these routines by hand; now every such routine in all three games is protected at start
  (162 in Drake's Fortune, 144 in Uncharted 2, 153 in Uncharted 3), with no speed cost. Please
  tell us if a crash like this still happens.
- **RivaTuner's on-screen display flickered** (#127 #128): when RivaTuner runs, the game now
  presents its frames the way RivaTuner expects.
- **Uncharted 2 ultrawide: shadows at the sides of the screen** came and went as the camera
  turned at 21:9 and 32:9. Thanks to Ferosnow95 (#192).

## New

- **Drake's Fortune: mouse aiming without the "stick" feel** (#190): aiming now turns directly
  from the mouse, like Uncharted 2 and 3 since 0.6.0: the same movement turns the same angle,
  slow or fast, with no speed cap and no acceleration.

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.
