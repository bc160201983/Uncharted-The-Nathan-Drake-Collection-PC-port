**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
Support the work on [Patreon](https://www.patreon.com/c/bilalreloaded).

The launcher offers this update: press **UPDATE TO 0.7.2** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

More frames and fewer stutters on every CPU, sharp aiming again at high resolutions, a fix for an
Uncharted 3 crash and a gamepad fix.

## Faster

The thread that feeds the graphics card was waiting on Windows and on memory housekeeping.
Measured in our tests (same save, same spot, before -> after):

| Game | CPU | FPS | 1% low |
|---|---|---|---|
| Uncharted 2 | all cores | 93 -> 116 | 67 -> 84 |
| Uncharted 2 | 4 cores | 67 -> 84 | 31 -> 34 |
| Uncharted 1 | all cores | 94 -> 120 (limit) | 56 -> 104 |
| Uncharted 3 | all cores | 116 -> 120 (limit) | 102 -> 109 |

Measured at a 120 FPS limit with the game window in the background; gains depend on your PC, and
slower CPUs and laptops gain the most in smoothness (1% lows).

## New options

- **Texture filtering** (launcher -> Advanced): Game / 4x / 8x / 16x for all three games, sharper
  ground and walls at an angle, almost no frame-rate cost.
- **Sharper lamp shadows** and **Full-resolution textures** (Uncharted 2 and 3, Advanced): the
  games' own higher-quality settings that were off on the PS4. Off by default.
- **In-game menu shortcut** in the launcher (#300): L2 + R3, Select + Start or keyboard only (L2 +
  R3 also zooms the scope with some guns).
- **Check game files** (Advanced -> FOLDERS): lists every file missing from your game folder.

## Fixed

- **Blurry aiming** (#276): with multithreaded rendering on and above 1080p (DLAA, 1440p,
  3440x1440, 4K), the aim focus point was taken from beside the crosshair, so everything but Nate
  was blurred. Fixed in Uncharted 2 and 3.
- **Uncharted 3: crash in "Stay in the Light"** (#284): a light pointing in one exact direction
  made the game's own shadow-camera check stop the game. That light now keeps its last good
  frame instead.
- **Gamepad stops responding** until a key is pressed, or in exclusive fullscreen (#281, thanks
  to vladector).
- **No mouse cursor in the in-game menu** (#300).

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): in the logs we have, the
  game stops because a file of the game is missing from the player's dump
  (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files** in the launcher shows it.
- **GeForce GTX 10-series: crash at start** (#211 #219 #252 #285). Being looked at.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.
