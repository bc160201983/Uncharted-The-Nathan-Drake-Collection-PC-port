Uncharted 3 no longer washed out on RTX 30 and 40 cards, subtitles over Uncharted 3's movies with
upscaling, fixes for start and chapter 8 crashes, an IGPU preset and Add to Steam in the launcher.

## Fixed

- **Uncharted 3 washed out / too bright on GeForce RTX 30 and 40 cards** (#199 #195 #204 #212):
  the game's automatic exposure measured the picture wrong on these cards (its brightness sum
  relied on a detail of the PS4's GPU), so everything came out about twice as bright. It is now
  measured correctly on every card. Thanks to everyone who answered the questions in those issues.
- **Uncharted 3: subtitles missing over movies with DLSS, FSR or TAA upscaling** (#237 #243 #222).
- **AMD: crash at start after a while, or after changing upscaling** (#230 #201 #206 #185): saved
  shaders could be paired with the wrong parts when loaded. They are now loaded only with the
  parts they were saved with, and if a game ever stops while loading its saved shaders, the next
  start clears and rebuilds them by itself.
- **Uncharted 2 and 3 on game version 1.00: crash in chapter 8** (`m_lookAt`, #148, likely #210):
  the fix from 1.02 now covers 1.00 too.
- **"Update 1.02" shown although the games are 1.00** (#148 #176): a 1.02 version file with the
  1.00 game files is now detected, and the launcher shows the "install update 1.02" warning.

## New

- **Advanced -> Uncharted 3 exposure**: an optional setting to make Uncharted 3 darker if you still
  find it too bright (-0.3, -0.6 or -1.0; "Game's" = unchanged). Based on pavlikdcx's patch (#199).
- **IGPU preset** for Intel and AMD integrated graphics: 540-720p with FSR 1 to 1080p (adapted from
  PR #223 by memeguyoffical).
- **Add to Steam** (Advanced -> STEAM): adds the port to your Steam library as a non-Steam game,
  with pictures made from your own game files. Close Steam first.

## Known issues

- **Rare "device lost" crashes** during play (#224 #200 #229): please start with
  `GOW3_GPU_CHECKPOINTS=1` and attach boot.log.
- **Uncharted 2 title or pause text flickering on some AMD cards** (#236). Being looked at.
- **Movies (FMV) slower than the sound** on some PCs (#77). Being looked at.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.
