**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
Support the work on [Patreon](https://www.patreon.com/c/bilalreloaded).

On 0.5.0 or older? The launcher offers this update: press **UPDATE TO 0.6.0** next to PLAY.

Crash fixes, half the RAM, mouse aiming without the "stick" feel, save profiles and more.

## Fixed

- **Uncharted 2: the most common crash**, "read access to 0 at guest offset 0xd09665" (#61 #113
  #115 #164 #181 #187), often around trains: a particle routine lost one of its values when
  Windows handled a page fault in the middle of it. Please tell us if it still happens.
- **Crash on a broken texture** in Uncharted 1 and 2 ("pixel_format.cpp NumBitsPerBlock", #144
  #155 #157).
- **Games stopping at start with update 1.02 in a separate folder** ("files.json -> not found",
  "ASSERTION: root"; #43 #73 #139 #151 #153 #165 and others): on PCs where Windows allows symbolic
  links (Developer Mode, or the launcher run as administrator), the game read the update's files
  as empty.
- **Half the RAM and a faster start** (#186 #95 #100): Uncharted 2 used 15.5 GB of RAM in our test,
  now 7.0 GB, and shader loading at the start takes about 10 s instead of 40 s. The old
  "pipeline-binaries" folder (up to 20 GB) is deleted at the first start.
- **Shader-compile freezes that 0.5.0 still had** (#144 #132 #142 #117).
- **Uncharted 3 too bright in sunny areas** (#140): the bloom (the glow around bright light) now
  reaches the picture instead of a stale haze.
- **Updating keeps your own files** (#134): ReShade files, notes or a game folder you put into the
  port's folders are no longer removed by the launcher's update.
- **The update download continues after a stall** (#150) instead of failing.

## New

- **Mouse aiming without the "stick" feel** (#190 #86 #141 #158 #170): aiming in Uncharted 2 and
  3, and the camera in Drake's Fortune, now turn directly from the mouse: the same movement turns
  the same angle, slow or fast, with no speed cap and no acceleration. Sensitivity goes up to 5x
  in the launcher (10x in the in-game menu). Cover and Drake's Fortune's aiming still use the
  previous method for now.
- **Save profiles** (#66): launcher Advanced -> Save profile. Three per game, each with its own
  progress and in-game settings. Profile 1 holds your existing saves; switching never deletes one.
- **Controller vibration on/off** (#166): launcher Controls and the in-game Controls tab.
- **Mouse side buttons** can be bound in the launcher (#152).
- **Temperatures in the performance counter** and the counter's settings on the launcher's
  Display tab (#178 #179, thanks to memeguyoffical).
- A crash message now says when the game is version 1.00 without update 1.02, and device-lost
  crash logs include the graphics driver's fault report.

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Japanese, Korean and Chinese** can't be selected in the European copy (#108). Being looked at.
- **Movies (FMV) slower than the sound** on some PCs (#77). Being looked at.
- **Rare "device lost" crashes** after long sessions (#130 #132 #183): the new driver report in
  boot.log will tell us more. Please attach it.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more.

> **No game files are included.** You need your own dump of the Collection. Not affiliated with
