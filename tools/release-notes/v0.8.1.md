**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
Support the work on [Patreon](https://www.patreon.com/c/bilalreloaded).

The launcher offers this update: press **UPDATE TO 0.8.1** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

Uncharted 1's water has its reflections back, and the mouse now turns the camera at full speed in
cover and next to walls. There is a new shortcut to close the game, and fixes for GeForce GTX
10-series cards and Intel graphics.

## Uncharted 1 water

- **Water reflections and colour** (#161 #306 #253 #331 #336): Drake's Fortune's water was a flat,
  dark green with no reflections, in the whole game. Each frame the game draws the reflection
  with a depth buffer that it clears in a way our port lost track of, so nearly the whole
  reflection came out black. The clear is now kept: walls, pillars, buildings, trees and the jet
  ski reflect again and the water has its PS4 colour (checked against the PS4 pictures in #161).
  No frame rate cost.

## Mouse

- **In cover** (all three games, #250 #291 #275 #190 #158): behind cover, the mouse turned the
  camera very slowly, because cover still treated it as a controller stick. It now turns the camera
  directly, the same as outside cover: left, right, up and down.
- **Next to walls** (all three games): close to a wall or in a narrow spot, the camera could stick or
  slow down while turning with the mouse, although a controller was fine there. The games only
  counted the stick as "the player is turning the camera", so near walls they pushed the camera
  back. They now count the mouse too.
- **Camera changes** (starting or stopping to walk, grabbing a ledge): a mouse turn during the
  change is no longer lost.
- Still to do: the mouse on mounted guns (#250).

## New

- **Close the game with a held shortcut:** hold **L1 + R1 + Share + Options** (Xbox: **LB + RB +
  View + Menu**) or **Ctrl + Shift + Q** for 2 seconds. A countdown shows on screen; let go to
  cancel. Progress since the last checkpoint is lost, as when closing the window. It can be turned
  off in the in-game menu (Insert) -> Controls.

## Fixed

- **GeForce GTX 10-series: crash at start** (#211 #219 #252 #285): an optional driver feature the
  port uses for crash reports made these cards fail at start. It is now off on GeForce cards older
  than the RTX 20-series. Thanks to the player who tested the workaround. Please tell us if it
  starts for you now.
- **Intel graphics: Uncharted 3 chapter 2 stops and Nate's bag disappears** (#328): Intel's driver
  could run some of the game's compute shaders with a different number of lanes than the port
  built them for. They now always run with the number they were built for. We have no Intel
  graphics to test with, so please tell us how it works for you.
- **Uncharted 3, Xbox buttons: a PlayStation circle at the bar-fight chokehold** (#327).

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Performance

About the same frame rate as 0.8.0 (the same saves, 1080p, 120 FPS limit; 0.8.0 -> 0.8.1):

| Game, CPU | FPS | 1% low |
|---|---|---|
| Uncharted 2, all cores | 114 -> 114 | 72 -> 69 |
| Uncharted 2, 4 cores | 84 -> 82 | 32 -> 34 |
| Uncharted 1 and 3, all cores | 120 (limit), unchanged | unchanged |
| Uncharted 1, 4 cores | 101 -> 100 | 35 -> 35 |
| Uncharted 3, 4 cores | 119 -> 117 | 53 -> 48 (average of several runs) |

Uncharted 3 on 4 cores came out about 2% lower in our runs. Turning the new mouse code off made no
difference, so it is most likely the spread between runs; tell us if you notice it. 5-minute runs of
all three games, Uncharted 3 with DLSS, FSR 4 and TAA, and a start with an empty shader cache: no
problems.

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): a file of the game is
  missing from those dumps (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files**
  in the launcher shows it.
- **NVIDIA: "device lost" after some time in Uncharted 2 and 3** (#316 #314 #277 #76 #224 #249):
  not solved yet. If it happens, please attach your boot.log.
- **Game version 1.00 without update 1.02:** most of the port's fixes need update 1.02. Support for
  1.00 is being worked on.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more
   are recommended; for 2-4 GB cards, try **Save video memory** (experimental).
