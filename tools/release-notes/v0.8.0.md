**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
Support the work on [Patreon](https://www.patreon.com/c/bilalreloaded).

The launcher offers this update: press **UPDATE TO 0.8.0** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

Smoother motion with VSync, older CPUs supported, faster heavy scenes, fixes for AMD menus and
several crashes, and save protection against power cuts.

## Smoother

- **Jerky camera with VSync** (most noticeable in Uncharted 1): when the frame rate matched the
  monitor (for example 75 FPS on a 75 Hz screen), some sessions ran the game in uneven pairs of
  frames: the counter said 75 FPS but the motion looked like half of that. The port's frame pacing
  could leave an extra frame waiting for the screen and never catch up. Fixed in all three games;
  in our tests every session is now smooth.
- **Idle game threads: Auto** (#274) now keeps Uncharted 1's helper threads awake (Spin) on CPUs
  with 8 or more threads, where it smooths the camera. Uncharted 2 and 3 keep Sleep, as before.

## Faster in heavy scenes

The thread that feeds the graphics card no longer waits behind other threads. Measured against
0.7.2 at the spots we test (the same saves, 1080p, 120 FPS limit, before -> after):

| Game, CPU | FPS | 1% low |
|---|---|---|
| Uncharted 2, all cores | 112 -> 117 | 81 -> 90 |
| Uncharted 3, 4 cores | 119 -> 120 (limit) | 56 -> 60, stutters 117 -> 76 a minute |
| Uncharted 1 | 120 (limit), unchanged | unchanged |

Without the frame-rate limit, Uncharted 2 at that spot went from about 121 to 132 FPS. On 4-core
CPUs Uncharted 2 stays about the same.

Gains depend on your PC; the frame-rate limit caps them on fast PCs.

## Older and smaller PCs

- **Older CPUs now run the games** (#154, #299): Intel 2nd and 3rd generation Core (Sandy Bridge,
  Ivy Bridge, for example the i5-3570 or i7-2600) and AMD FX. Before, a 4th generation (Haswell)
  or newer CPU was needed. The few instructions these CPUs lack are carried out by the port.
- **Experimental: Save video memory** (launcher -> Performance), for graphics cards with 2-4 GB:
  about 30% less video memory (Uncharted 2 at 720p: 2.1 -> 1.5 GB) with the same picture. It is
  new and we have not been able to try it on a real 2 GB card yet, so it is **off** unless you turn
  it on. Please tell us how it works for you.

## New options

- **No depth of field** (Uncharted 2 and 3, launcher -> Advanced, #169): turns off the background
  blur while aiming, in cutscenes and in gameplay. Needs update 1.02.
- **Stretch movies to the screen** (Advanced, #145): the prerecorded cutscenes are 16:9; on
  ultrawide screens they keep their shape with black bars unless this is on.

## Fixed

- **AMD Radeon: flickering menus and black blocks at 1080p and 1440p** (#236, #278, #325): with
  sharpening on, the sharpening pass could read the picture before the graphics card had finished
  drawing the menu.
- **Thin bright line at the right and bottom edges** with FSR 4 or TAA (#297, #325): the
  sharpening pass read past the picture's edge. Please tell us if you still see it.
- **Crash "read at 0x20"** in all three games (#205, #304, #326): a game job could run without its
  parameters.
- **Uncharted 3, chapter 2: graphics driver stop** (#328 and others): two effect shaders could loop
  on garbage counts.
- **Crash at start on PCs whose video memory is almost full.**
- **Uncharted 3 movies playing at double speed** at 120 FPS.
- **Uncharted 1 and 2: "pAction" stop at high frame rates** (#293): the player's move-action pool
  is larger. Tell us if it still happens.
- **Quick button taps on a controller were missed** (#309, for example the lever in Uncharted 1's
  Treasure Vault): a press and release between two of the game's pad reads now counts. Tell us if
  it still happens.
- **Saves after a power cut** (#311): a save is now written to disk as soon as the game finishes
  it, and the port keeps a copy of the last good save. If a save is found empty after a power cut
  or crash, that copy is put back when the game loads it.

Full details in [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): a file of the game is
  missing from those dumps (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files**
  in the launcher shows it.
- **GeForce GTX 10-series: crash at start** (#211 #219 #252 #285). Being looked at.
- **NVIDIA: "device lost" after some time in Uncharted 2 and 3** (#316 #314 #277 #76 #224 #249):
  not solved yet. This version removes two invalid graphics settings the games sometimes hand
  over just before these crashes, but we could not show that they cause them. If it still
  happens, please attach your boot.log.
- **Uncharted 3: a PlayStation button picture at some quick-time events** (#327).

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more
   are recommended; for 2-4 GB cards, try **Save video memory** (experimental).
