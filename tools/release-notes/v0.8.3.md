The launcher offers this update: press **UPDATE TO 0.8.3** next to PLAY. Still on 0.6.1 or older
(the launcher does not open)? Extract the zip below over your port folder once.

This update is about crashes: GeForce cards losing the graphics device in Uncharted 1 and 2,
Uncharted 3's crash after the museum, games that froze or closed after playing a while, and a new
crash report option that names the exact spot where the graphics card stopped.

## Crashes fixed

- **GeForce, "device lost" while playing** (#350 #362 #353, and maybe #316 #314 #277): two of the
  games' skinning shaders run in groups of 1024 threads, and on NVIDIA cards such a group needs a
  whole block of the graphics card to itself, which can make the card fail under load. They now
  run in groups of 256, with the same result.
- **Uncharted 3, the crash after young Nate leaves the museum** (#292 #295 #354 #328): a shadow
  shader reads how many samples to take from the game's data, and a bad value made it loop until
  the graphics card was reset. The count is now limited to what a shadow ever needs.
- **Games freezing with no error:** a lock in the port's memory code could wait for itself when a
  game thread wrote a reply into memory the graphics card was watching.
- **Games closing after playing a while** (#362 #330 #335 #341): when part of a memory range was
  given back, the pages next to it were missing for a moment, and a game thread touching them
  closed the game. Those threads now wait for that moment to pass.
- **Long sessions: "code is too big":** the space for small code the port writes for each shader
  only ever grew, also for identical code. Identical code is now shared.
- **Two rare crashes on broken game data:** a broken texture description could make the port
  allocate memory until it ran out, and a texture-cache list could be read while it changed.

## For crash reports

- If a game still closes with **"device lost"**: create the text file
  `analysis\uncharted-user\test-env.txt` in the port folder with the line `GOW3_GPU_BREADCRUMBS=1`,
  and play to the crash once more. The game runs a little slower, and `boot.log` then names the
  shaders the graphics card stopped in. Please attach that `boot.log` (delete the file afterwards).

## Known issues

- **Movie cutscenes freezing while the sound goes on** (#226 #262 #270 #177): not fixed yet. If it
  happens, please attach the `hang-*.txt` file the port writes next to boot.log.
- **Uncharted 3, chapter 8 "The Citadel": crash** (#247 #296 and others): a file of the game is
  missing from those dumps (`ss-area2-breakable-buildings-controller-1.bin`). **Check game files**
  in the launcher shows it.
- **NVIDIA: "device lost" after some time in Uncharted 2 and 3** (#316 #314 #277 #76 #224 #249):
  not solved yet. If it happens, please attach your boot.log.
- **Game version 1.00 without update 1.02:** most of the port's fixes need update 1.02. Support for
  1.00 is being worked on.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**. Graphics cards with 6 GB of video memory or more
   are recommended; for 2-4 GB cards, try **Save video memory** (experimental).
